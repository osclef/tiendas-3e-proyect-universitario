# Proyecto: Sistema Web + Integración Supabase

## 🧠 Descripción
Este repositorio contiene el desarrollo de un sistema web con frontend y conexión a Supabase como backend base.

---

## ⚙️ Trabajo realizado

### 🟦 Fase 1 (Frontend - base inicial)
- Diseño y estructura de interfaz
- Lógica en JavaScript
- Flujo de usuario inicial

### 🟩 Fase 2 (Backend / Supabase - integración)
- Conexión a Supabase
- Uso de API keys (anon key)
- Vinculación de base de datos con frontend
- Implementación de login simulado / estructura de autenticación base

---

## 🚫 Pendiente / no incluido
- Implementación completa de RLS (Row Level Security)
- Backend de autenticación avanzado
- Sistema de permisos o roles complejos

---

## 📌 Notas
- Este proyecto representa una implementación funcional en fase MVP.
- Cualquier uso o modificación futura requiere autorización del autor.
